# PRE-BUILD CHECKLIST

Sebelum menjalankan master prompt, pastikan:

- [ ] PRD sudah direview.
- [ ] SRS tidak bertentangan dengan proposal final.
- [ ] Tech stack diterima.
- [ ] Semua screenshot final yang sudah ada dimasukkan `references/`.
- [ ] Splash/Menu/Petunjuk/Tentang production assets sudah disalin ke `assets/`.
- [ ] Marker buku MRK-B01…B10 final tersedia.
- [ ] Marker wayang final dan jumlah tokoh sudah ditetapkan.
- [ ] `scenes.json` sudah diisi judul/cerita final.
- [ ] `characters.json` sudah diisi dari sumber tervalidasi.
- [ ] Audio ID/EN sudah tersedia atau statusnya jelas.
- [ ] Model/animasi tiap adegan tersedia atau statusnya jelas.
- [ ] Sumber cerita pada Tentang sudah final.
- [ ] Identitas pengembang/institusi sudah final.
- [ ] Semua nama file menggunakan snake_case tanpa `&`/spasi.
- [ ] Target device fisik ARCore tersedia untuk pengujian.

Semakin banyak item yang belum dicentang, semakin besar peluang coding agent menghasilkan build yang secara teknis lengkap tetapi belum dapat dianggap final secara konten.
